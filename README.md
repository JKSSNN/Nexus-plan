# NEXUS — мобильный планер

NEXUS — адаптивный веб-планер с тёмным технологичным дизайном. Работает в браузере, хранит ваши данные в `localStorage` на устройстве и поддерживает установку на главный экран как PWA после публикации по HTTPS.

## Что включено
- Обзор дня и задачи
- Месячный календарь с отметками дней, на которые добавлены задачи
- Задачи с датой, временем и категорией (личное, учёба, работа, здоровье)
- Расписание по часам
- Сон, вода, привычки, питание и тренировка
- Цели, мотивация и заметки
- Локальная статистика
- Кэш оболочки для базовой работы офлайн после первого посещения

## Самый простой запуск
Откройте `index.html` в браузере. Основные функции и локальное сохранение будут работать, но установка как полноценного PWA и офлайн-кэш требуют публикации по HTTPS.

## Как установить на телефон
### Android (Chrome)
1. Опубликуйте файлы сайта по HTTPS (например, через GitHub Pages).
2. Откройте адрес сайта в Chrome.
3. Нажмите меню `⋮` → «Установить приложение» или «Добавить на главный экран».

### iPhone (Safari)
1. Откройте адрес сайта в Safari по HTTPS.
2. Нажмите «Поделиться».
3. Выберите «На экран Домой» → «Добавить».

## Публикация через GitHub Pages
1. Войдите на GitHub и создайте новый публичный репозиторий, например `nexus-planner`.
2. Загрузите в корень репозитория файлы `index.html`, `manifest.webmanifest`, `sw.js`, `icon.svg`.
3. Откройте Settings → Pages.
4. В разделе Build and deployment выберите `Deploy from a branch`, ветку `main`, папку `/ (root)`, затем Save.
5. Дождитесь публикации и откройте показанный GitHub Pages URL на телефоне.
6. Добавьте сайт на главный экран инструкцией выше.

## Важно о сохранении
- Данные сохраняются в локальном хранилище браузера на том устройстве, где вы ими пользуетесь. Они не синхронизируются автоматически между телефоном и компьютером.
- Не очищайте данные сайта/браузера, иначе локальные записи могут быть удалены.
- Для резервной копии используйте экспорт данных из браузера или добавьте отдельную функцию экспорта; в этой версии облачной синхронизации и экспорта нет.
- Публикация на GitHub Pages размещает код приложения, но не передаёт GitHub ваши задачи из localStorage.
